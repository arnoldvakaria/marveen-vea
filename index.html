MarveenVEA

MarveenVEA is a private, self-hosted AI assistant used by a single household. It is not a public service and has no sign-up.

What it does

  • Reads the owner's Gmail inbox to summarize new messages in a morning briefing.
  • Reads and manages events in the owner's Google Calendar.
  • Reads and edits the owner's own Google Docs and Sheets on request (for example shared household lists).

All processing runs on the owner's own computer. Google account access is used only by the owner, for the owner's own data.
