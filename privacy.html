Privacy Policy

Last updated: 28 October 2026

MarveenVEA is a private, self-hosted assistant. Its only users are the owners of the Google account it is connected to. This policy describes how it handles Google user data.

Data accessed

  • Gmail (read-only): message headers and content, to summarize new email.
  • Google Calendar: events, to list and manage the owner's appointments.
  • Google Drive, Docs and Sheets: files the owner works with, to read and edit them on request.
  • Basic profile and email address: to identify the connected account.

How the data is used

Google user data is used only to provide the assistant features to the account owner. It is processed on the owner's own computer. It is not sold, not used for advertising, and not shared with third parties, except that text may be sent to the AI model provider the owner has chosen in order to generate a reply for the owner.

Storage and retention

OAuth tokens and any cached content are stored locally on the owner's computer, with file permissions restricted to the owner. The owner can delete them at any time. Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

MarveenVEA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
